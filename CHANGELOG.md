# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-28

### Added
- Initial release of react-native-tour-guide
- `TourGuideProvider` component for managing tour state
- `TourGuideStep` component for marking elements in the tour
- `useTourGuide` hook for programmatic tour control
- `Overlay` component with circle and rectangle highlight shapes
- `Tooltip` component with auto-positioning
- TypeScript support with full type definitions
- Comprehensive documentation and examples
- Sequential step navigation (next, previous, skip)
- Event callbacks (onStepChange, onComplete, onSkip)
- Customizable overlay color and opacity
- Multiple tooltip positioning options (top, bottom, left, right)
- Example application demonstrating all features
